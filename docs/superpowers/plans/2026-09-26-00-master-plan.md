**Goal:** Take every open item in `docs/03-BACKLOG.md` to done, in an order where each step leaves
the harness runnable and each task can be implemented by a model that has never seen this repo.

**Architecture:** VerNess is a capability layer on top of the DeepSeek Harness (`dsh`) / Cordis
substrate. It has two code bases that must not be confused:

1. **The launcher** (`scripts/`, plain Node ESM `.mjs`, zero dependencies). It runs *outside* the
   agent loop: REPL, quick-tools (`/cmd`), model and sidecar lifecycle, teams, loop driver,
   dashboard, pet. Most open work is here, and all of it can be built and tested without the
   substrate running.
2. **Substrate plugins** (`packages/*`, Cordis plugins mounted into the `verness` dsh profile). Today
   only `packages/spike` exists (plain JS). M2–M9 add TypeScript packages that attach to documented
   seams (`system-prompt/assemble`, `tools/pre-execute`, `agent/request`, …) and never edit the
   agent loop.

**Tech stack:** Node ≥ 22.19 (this machine: 26.10), ESM, `node:test` + `node:assert/strict`,
pnpm 11.7.0 (profile installs only), `@deepseek-ai/dsh@0.1.7-rc.2`, `@deepseek-ai/cordis@4.0.4`,
Ollama for the local model, the Laya sidecar (Python, optional) for decisions.

**Spec (read before any task):**

## Global Constraints (every task inherits these)

- `upstream/` is **read-only**. Never edit or commit inside the submodule.
- No vendor names outside `providers/` and adapter files (law 2, ADR-0003). `Laya`, `Jev`, `Ollama`
  may appear only in adapter/provider code, config and docs.
- Launcher code: plain `.mjs`, **no npm dependencies**, JSDoc on every exported function, match the
  file's existing style (2-space indent, no semicolons, single quotes, `===`, early returns).
- Output goes through the helpers in `scripts/lib/util.mjs` (`head`, `step`, `ok`, `warn`, `info`,
  `line`, `paint`, `table`). Colour only when `process.stdout.isTTY`.
- Commands are one file each in `scripts/commands/`, default-export
  `{ name, aliases?, group, summary, usage, details?, run(ctx, args) }`, return an exit code, and
  **cost zero tokens** unless their summary says otherwise.
- Mutable launcher state goes to `.verness/state.json` via `readState`/`writeState`
  (`scripts/lib/personas.mjs`). **Never rewrite `verness.config.json`**; it is commented JSONC and
  operator-owned.
- Everything under `.verness/` is gitignored run state.
- Anything that spawns `dsh` uses the shell-free `dsh()` runner (or `dshAsync()` once WS-B T-144
  lands), never `sh('dsh', …)`. `cmd.exe` truncates multi-line prompts.
- Network services bind **127.0.0.1** by default. Anything wider needs a generated token.
- Decision-model output never steers behaviour until the T-223 gate passes. Until then: shadow-log.
- Commits: conventional prefix + task ID (`feat(teams): run tasks concurrently (T-144)`).
  **`docs/05-CONVENTIONS.md` says: authorship is the repository owner only, no co-author or
  tool-attribution trailers.** That repo rule wins over any default trailer.
- Every finished task: tick it, **move the line to `docs/03-BACKLOG-DONE.md`** with one line of
  evidence, append a dated entry to `docs/04-PROGRESS.md`, commit.
- Before claiming a feature ships, verify from a clean clone:
  `git clone . "$(mktemp -d)/fresh" && cd "$_" && node scripts/verness.mjs help`.
- Tests: `node:test` files in `scripts/test/*.test.mjs`, run with `npm test` (made real by WS-A
  Task 1). Tests never need the network, the model or the sidecar: stub `fetch`, spawn fake
  scripts, point `DSH_HOME` at a temp dir.

## Review Focus (failure modes no single task's tests fully cover)

1. **Windows paths and quoting.** Every new spawn must work through `turn_on.cmd` with a prompt
   containing a newline, a `%`, and a double quote. Any task that spawns a process adds that case.
2. **Piped (non-TTY) output.** Every command must print plain text with no escape codes when
   stdout is not a TTY (`node scripts/verness.mjs <cmd> | cat`). Pet/editor tasks assert it.
3. **Concurrent sessions sharing `~/.dsh`.** Two checkouts or two REPLs share one profile patch
   (T-336). Any task writing into `$DSH_HOME` must say whose state it overwrites.
4. **Missing optional services.** Engine down, sidecar down, no session logs yet, empty
   `.verness/`. Every command prints a one-line reason and exits non-zero or zero deliberately; it
   never throws a stack trace.
5. **Unbounded growth.** Notes (`/btw`), briefs (`#`), shadow logs, loop logs, thought nodes:
   anything that is resent to the model or kept forever has a cap and says so when it is near it.

## Orientation for a model new to this repo (read once)

- **Entry point:** `scripts/verness.mjs`. `dispatch()` (bottom of the file) routes CLI words;
  `cmdRun()` is the REPL loop (look for `for (;;)`); `makeCtx()` builds the object every command
  receives: `{ conversation, cfg, commands, sh, dsh, sync, routeEnv, activePersonaId, workspaceKey, builtins }`.
- **Command registry:** `scripts/lib/commands.mjs`. `loadCommands()` imports every
  `scripts/commands/*.mjs` and registers the default export plus any named export shaped like a
  command; `runCommand(input, ctx)` strips a leading `/` and dispatches on the first word.
- **Config:** `loadConfig()` in `scripts/verness.mjs` merges `DEFAULTS` with `verness.config.json`
  **shallowly per top-level section**. A new config section needs a default in `DEFAULTS`.
- **Personas:** `scripts/lib/personas.mjs` (`loadPersonas`, `activePersonaId`, `readState`,
  `writeState`, `describePersona`, `writePersonaOverlay`). Files are `personas/<id>.json`.
- **Teams:** `scripts/lib/teams.mjs` + `scripts/commands/team.mjs`. Files are `teams/<id>.json`.
- **Session logs:** `scripts/lib/sessions.mjs` reads `$DSH_HOME/sessions/**/session.v4.jsonl.zstd`
  (concatenated zstd frames) and exposes `listSessions`, `readSessionEvents`, `summarizeSession`,
  `aggregateUsage`, `priceUsage`.
- **Decisions:** `scripts/lib/decisions.mjs` (SystemOne client, `ROUTING_QUESTIONS`, `ruleRoute`,
  `logShadowDecision` → `.verness/decisions/<day>.jsonl`), lifecycle in `scripts/decision.mjs`.
- **Loop:** `scripts/lib/loop.mjs` (primitives) + `scripts/loop-task.mjs` (driver) → `.verness/loops/`.
- **Dashboard:** `scripts/dashboard.mjs` (`buildDashboard(cfg, opts)`) → static HTML.
- **Pet:** `scripts/lib/pet.mjs` (`gatherVitals`, `moodOf`, `petArt`, `petAnimFrames`,
  `animatePet`, `renderPet`, `petEnabled`).
- **Tests today:** `scripts/test/pet.render.mjs` and `scripts/test/prompt.simulated-tty.mjs`, plain
  assert scripts. WS-A Task 1 turns them into `node:test` suites.
- **Run it:** `./turn_on.sh doctor` (macOS/Linux) or `.\turn_on.cmd doctor` (Windows). A command
  runs without the REPL: `node scripts/verness.mjs help`, `node scripts/verness.mjs team list`.
