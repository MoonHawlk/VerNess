# WS-F — M2 Contracts (`@verness/contracts`) and persona schema v2: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax. Read
> `2026-09-26-00-master-plan.md` and `docs/01-ARCHITECTURE.md` §"Core contracts" first.
> Requires WS-A Task 1.

**Goal:** Freeze the project vocabulary as TypeScript types plus runtime validators, with zero
runtime behaviour, and use the validators at once for persona files (with `file:line`
diagnostics) so the contracts are exercised by real data from day one.

**Architecture:** One package, `packages/contracts/`, written in **erasable-only TypeScript** (no
`enum`, no `namespace`, no parameter properties, no decorators). Node ≥ 22.18 strips types natively,
and the repo requires ≥ 22.19, so:
- the launcher (`scripts/*.mjs`) imports validators directly from `packages/contracts/src/*.ts`, with no build step;
- tests run with `node --test` on `.ts` files, with no build step;
- `tsc` is a **dev-only** dependency, used for `npm run typecheck` and to emit `lib/` for the
  substrate plugins (WS-G), which are installed into the dsh profile's `node_modules`, where Node
  does not strip types.

Validators are hand-written (no schemastery, no zod): the launcher must stay dependency-free at run
time, and the shapes are small. Each returns `{ok: true, value} | {ok: false, errors: Issue[]}`
where `Issue = {path: (string|number)[], message: string}`. `locate(text, path)` maps an issue path
to a `line:column` in the JSONC source.

**Tech stack:** TypeScript 5.x (`erasableSyntaxOnly`, `allowImportingTsExtensions`,
`verbatimModuleSyntax`), Node type stripping, `node:test`, pnpm workspace (already declared in
`pnpm-workspace.yaml`).

**Spec:** `docs/01-ARCHITECTURE.md` (contracts), `docs/02-ROADMAP.md` §M2 (exit: `tsc` clean,
round-trip tests, no vendor dependency), `BRAINSTORM.md` §§5, 13, 26–30 (original shapes),
`docs/07-COMMAND-LAYER.md` (persona file fields), `docs/research/deepseek-harness-digest.md` §5
(package invariants).

## Global Constraints
Inherit the master plan. Also:
- `packages/contracts` imports **nothing** at run time: no `@deepseek-ai/*`, no npm packages. The
  roadmap's M2 exit says "no dependency on any vendor package". `@deepseek-ai/cordis` appears only as a
  `peerDependency` + `devDependency` (convention), and no `src` file imports it.
- Explicit `.ts` import specifiers (`from './decision.ts'`). Type-only imports use `import type`.
- Package invariants (conventions): `name: "@verness/contracts"`, `type: "module"`,
  `main: "lib/index.js"`, `types: "lib/types/index.d.ts"`, `exports["."]` → `{types, default}` for the

- Persona files stay **JSON (JSONC)** as built. ADR-0008's YAML wording is superseded; Task 7

2. Unknown fields: a typo like `"tool": {...}` must be reported (`unknown field "tool" — did you mean

```ts
/** One validation problem: where (a JSON path) and what. */
export interface Issue {
  path: (string | number)[]
  message: string
}

/** A validator's outcome. `value` is the normalised input (defaults applied). */
export type Result<T> = { ok: true, value: T } | { ok: false, errors: Issue[] }

/** Render a path like `tools.allow[2]`. */
export function formatPath(path: (string | number)[]): string {
  return path.reduce<string>((s, p) => (typeof p === 'number' ? `${s}[${p}]` : s === '' ? p : `${s}.${p}`), '')
}

/** Closest candidate by edit distance, for "did you mean". Undefined when nothing is close. */
export function closest(word: string, candidates: readonly string[]): string | undefined {
  let best: string | undefined
  let bestD = Infinity
  for (const c of candidates) {
    const d = editDistance(word, c)
    if (d < bestD) { bestD = d; best = c }
  }
  return bestD <= Math.max(1, Math.floor(word.length / 3)) ? best : undefined
}

function editDistance(a: string, b: string): number {
  const dp = Array.from({ length: a.length + 1 }, (_, i) => [i, ...Array<number>(b.length).fill(0)])
  for (let j = 1; j <= b.length; j++) dp[0]![j] = j
  for (let i = 1; i <= a.length; i++) {
    for (let j = 1; j <= b.length; j++) {
      dp[i]![j] = Math.min(dp[i - 1]![j]! + 1, dp[i]![j - 1]! + 1, dp[i - 1]![j - 1]! + (a[i - 1] === b[j - 1] ? 0 : 1))
    }
  }
  return dp[a.length]![b.length]!
}
```

export type ModelCapabilities = Partial<Record<CapabilityKey, CapabilityLevel>> & { context?: number }
/** What a persona or task needs; same shape, read as minimums. */
export type CapabilityRequirements = ModelCapabilities

export function levelRank(l: CapabilityLevel | undefined): number {
  return CAPABILITY_LEVELS.indexOf(l ?? 'none')

/** Every requirement the capabilities fall short of, as `key: have < need`. Empty means eligible. */
export function capabilityGaps(have: ModelCapabilities, need: CapabilityRequirements): string[] {

  if (need.context !== undefined && (have.context ?? 0) < need.context) gaps.push(`context: ${have.context ?? 0} < ${need.context}`)

### Task 5: `locate()`: JSON path → `line:column` in JSONC text (T-163, part 1)

**Files:** `src/locate.ts`, `test/locate.test.ts`

**Interface:** `locate(text: string, path: (string|number)[]): {line: number, column: number} | undefined`.
1-based. It points at the **value** for a path when the value exists, and at the enclosing object's
opening `{` when the last key is missing (e.g. a required field that is absent).

Implementation approach: a single-pass scanner over the raw text that skips whitespace, `//` and
`/* */` comments, and strings (with escapes), and keeps a stack of containers, each
`{type: 'object'|'array', key?: string, index: number}`. When the current stack path equals the
target and a value starts, return its position. Trailing commas are tolerated because the scanner
never validates.

- [ ] **Step 1: Failing tests**

  "id": "data-scientist",
  "tools": {
    "allow": ["read", "grep",
      "sql.query"],
  },
}`

test('top-level value', () => assert.deepEqual(locate(text, ['id']), { line: 3, column: 9 }))
test('array element', () => assert.deepEqual(locate(text, ['tools', 'allow', 2]), { line: 6, column: 7 }))
test('missing key points at the parent object', () => assert.deepEqual(locate(text, ['tools', 'deny']), { line: 4, column: 12 }))
test('root', () => assert.deepEqual(locate(text, []), { line: 1, column: 1 }))

  assert.deepEqual(locate('{"a": "http://x", "b": 1}', ['b']), { line: 1, column: 24 })

### Task 7: Persona-scoped commands (T-165) and doc updates

**Interface:** a persona's `commands: ["profile-data"]` refers to `personas/<id>/commands/profile-data.mjs`,
same shape as `scripts/commands/*.mjs`. `loadCommands({persona})` loads them **after** the global
ones. A persona command that shadows a global name is refused with a warning (a persona cannot
redefine `/help`). They are only registered while that persona is active. The REPL reloads the
registry after `/persona <id>`.
